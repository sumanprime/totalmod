# @totalmod/core

Shared pieces of [totalmod](https://github.com/sumanprime/totalmod): the spec and request schemas (zod), the `totalmod.config.yaml` loader with fix-it error messages, the deterministic policy checks (`checkSpec`, `checkChanges`, `screenText`), signed preview tokens and requester hashing.
